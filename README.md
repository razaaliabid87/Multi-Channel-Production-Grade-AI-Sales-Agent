# Multi-Channel-Production-Grade-AI-Sales-Agent
Multi-Channel Production Grade AI Sales Agent (n8n, HubSpot-CRM, RAG, OpenAI, Qdrant-VectorDB, Gemini, Slack) that unifies Web Chat, Email, SMS &amp; WhatsApp into one customer identity, retrieves answers via RAG, books meetings, replies in the customer's language, and gates every quote behind human approval before it reaches a customer.
